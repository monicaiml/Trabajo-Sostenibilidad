# Estandares y Metricas de desempeño ambiental

> Debido al crecimiento de su actividad, la empresa presenta dos problemas ambientales principales:

- Huella de carbono, por la falta de un entorno para controlar emisiones y consumo que producen los vehiculos y las instalaciones.
- Gestión de residuos, debido al exceso del uso de embalajes sin control produciendo un desperdicio de cantidades.

Para resolver los problemas anteriores se propone el desarrollo de un dashboard web para que tenga un seguimiento de la diferente información, calcule los datos necesarios y nos facilite la toma de decisiones para poder tener un mayor control.
